# Учёт сотрудников ООО «Прибой»

## Описание проекта

Консольное приложение на языке Python, реализующее учёт сотрудников
организации ООО «Прибой».

Приложение предоставляет интерактивное меню и поддерживает следующие
функции:
- ввод данных о новых сотрудниках организации;
- вывод таблицы со списком всех сотрудников;
- изменение данных конкретного сотрудника;
- удаление информации о сотруднике;
- фильтрация сотрудников по стажу работы в организации;
- циклическая работа приложения до явного выхода пользователем.

## Требования к окружению

- Python 3.8 или выше.
- Операционная система: Windows / Linux / macOS.
- Дополнительные библиотеки не требуются (используется только
  стандартная библиотека Python).

## Установка и запуск

1. Склонируйте репозиторий в рабочий каталог:
   https://github.com/iDeeGee/Practice.Priboy.git
2. Запустите главный модуль:
    python main.py

## Главное меню приложения

При запуске пользователю предлагается выбрать один из пяти пунктов:
1. Ввести данные нового сотрудника.
2. Вывести таблицу со списком сотрудников.
3. Изменить данные сотрудника.
4. Удалить информацию о сотруднике.
5. Выйти из приложения.
Приложение работает циклически и завершает работу только после выбора
пункта «5. Выйти из приложения».
