# Техническая документация

## 1. Назначение программы

Программа реализует предметную область «Учёт сотрудников организации».
Основное функциональное назначение - интерактивное управление
списком сотрудников: добавление, просмотр, изменение и удаление записей,
а также фильтрация по стажу работы в организации.

## 2. Архитектура решения

Проект построен по модульному принципу и состоит из двух файлов:

| Модуль      | Назначение                                                     |
|-------------|----------------------------------------------------------------|
| worker.py   | Содержит описание класса Worker и вспомогательных конструкций. |
| main.py     | Реализует пользовательский интерфейс, интерактивное меню       |
|             | и логику работы программы.                                     |

Разделение на модули выполнено в соответствии с принципом единственной
ответственности (SRP): модуль `worker.py` отвечает за моделирование
предметной области, а `main.py` - за взаимодействие с пользователем.

## 3. Описание класса Worker

### 3.1. Поля класса

| Поле         | Тип     | Описание                              |
|--------------|---------|---------------------------------------|
| __surname    | str     | Фамилия и инициалы работника.         |
| __position   | str     | Название занимаемой должности.        |
| __salary     | float   | Заработная плата (в рублях).          |
| __hire_year  | int     | Год поступления на работу.            |

Все поля объявлены как приватные (по соглашению name mangling) для
обеспечения инкапсуляции. Доступ к полям осуществляется через
методы геттеры и методы сеттеры.

### 3.2. Конструкторы

| Конструктор           | Назначение                                                    |
|-----------------------|---------------------------------------------------------------|
| __init__              | Основной конструктор. Поддерживает параметры по умолчанию.    |
| from_line(cls, line)  | Альтернативный конструктор. Создаёт объект из строки вида     |
|                       | «Фамилия; должность; зарплата; год», разделённых «;».         |
| from_dict(cls, data)  | Альтернативный конструктор. Создаёт объект из словаря.        |

### 3.3. Деструктор

Метод `__del__` вызывается сборщиком мусора Python при удалении объекта.
В данной реализации выводит диагностическое сообщение в стандартный
поток вывода.

### 3.4. Методы изменения полей

| Метод           | Описание                                                |
|-----------------|---------------------------------------------------------|
| set_surname     | Устанавливает фамилию и инициалы.                       |
| set_position    | Устанавливает должность.                                |
| set_salary      | Устанавливает зарплату. Проверяет неотрицательность.    |
| set_hire_year   | Устанавливает год поступления. Проверяет диапазон       |
|                 | от 1900 до текущего года.                               |

### 3.5. Методы получения полей

| Метод           | Описание                                                |
|-----------------|---------------------------------------------------------|
| get_surname     | Возвращает фамилию и инициалы.                          |
| get_position    | Возвращает должность.                                   |
| get_salary      | Возвращает зарплату.                                    |
| get_hire_year   | Возвращает год поступления.                             |

### 3.6. Расчётные методы

| Метод              | Описание                                              |
|--------------------|-------------------------------------------------------|
| get_experience     | Возвращает стаж работы в организации в годах          |

| check_experience   | Возвращает True, если стаж строго превышает заданное  |

### 3.7. Методы отображения

| Метод     | Описание                                                       |
|-----------|----------------------------------------------------------------|
| display   | Возвращает строковое представление объекта в табличном виде.   |
| __str__   | Вызывается при использовании функции print().                  |
| __repr__  | Возвращает формальное строковое представление для отладки.     |

## 4. Описание главного модуля main.py

### 4.1. Функции модуля

| Функция                      | Назначение                                     |
|------------------------------|------------------------------------------------|
| input_user()                 | Запрашивает данные сотрудника с клавиатуры     |
|                              | с защитой от некорректного ввода.              |
| input_yes_no(prompt)         | Универсальная функция запроса в формате        |
|                              | «1. Да / 2. Нет». Возвращает True или False.   |
| print_workers(workers)       | Выводит список сотрудников в табличном виде    |
|                              | с нумерацией строк.                            |
| choose_worker(workers, name) | Выводит список и запрашивает номер записи      |
|                              | для операций изменения/удаления. Возвращает    |
|                              | индекс или -1 при отмене.                      |
| menu_add(workers)            | Реализация пункта 1 главного меню - добавление |
|                              | нового сотрудника.                             |
| menu_show(workers)           | Реализация пункта 2 главного меню - вывод      |
|                              | таблицы и опциональная фильтрация по стажу.    |
| menu_edit(workers)           | Реализация пункта 3 главного меню - изменение  |
|                              | любого из четырёх полей сотрудника.            |
| menu_delete(workers)         | Реализация пункта 4 главного меню - удаление   |
|                              | записи с подтверждением.                       |
| menu_filter(workers)         | Вспомогательная функция фильтрации по стажу.   |
| show_main_menu()             | Вывод главного меню приложения.                |
| main()                       | Точка входа в программу. Реализует главный     |
|                              | цикл работы приложения.                        |

### 4.2. Логика работы программы

1. Инициализация пустого списка сотрудников.
2. Вывод главного меню.
3. Ожидание выбора пользователя (1–5).
4. Выполнение соответствующей функции:
   - пункт 1 - добавление сотрудника(ов) с возможностью продолжить ввод;
   - пункт 2 - вывод таблицы и опциональная фильтрация по стажу;
   - пункт 3 - выбор сотрудника и изменение одного из его полей;
   - пункт 4 - выбор сотрудника и удаление записи с подтверждением;
   - пункт 5 - завершение работы приложения.
5. Возврат к пункту 2 до тех пор, пока пользователь не выберет «5».

### 4.3. Особенности реализации

- **Циклическая работа.** Главный цикл `while True` в функции `main()`
  завершается только при выборе пункта `5`.
- **Защита от некорректного ввода.** Во всех функциях реализована
  многоуровневая валидация: проверка выбора пункта меню, числовых
  диапазонов, номера сотрудника при выборе из списка.
- **Возможность отмены.** При выборе сотрудника из списка пользователь
  может ввести `0` для отмены операции.
- **Защита от работы с пустым списком.** Функции `menu_show`, `menu_edit`,
  `menu_delete`, `menu_filter` проверяют, не пуст ли список сотрудников.
- **Подтверждение удаления.** Перед удалением записи запрашивается
  подтверждение через `input_yes_no`.
- **Единообразие интерфейса.** Все вопросы типа «да/нет» используют
  единый формат «1. Да / 2. Нет».

## 5. Хранение объектов

Объекты класса `Worker` хранятся в стандартном списке `list` языка
Python, который является динамическим массивом. Это обеспечивает гибкость
при добавлении и удалении элементов.

## 6. Обработка ошибок

Во всех функциях ввода реализована защита от некорректных данных:
- проверка типа вводимых значений (число / строка);
- проверка диапазонов (зарплата ≥ 0, год в пределах 1900–текущий год);
- обработка исключений `ValueError` с повторным запросом ввода;
- обработка исключений `ValueError` в сеттерах класса `Worker`
  с выводом сообщения об ошибке.
