# Руководство пользователя

## 1. Назначение программы

Программа предназначена для интерактивного ведения учёта сотрудников
организации ООО «Прибой» и выполнения операций над записями:
добавления, просмотра, изменения, удаления, а также фильтрации по стажу.

## 2. Запуск программы

Для запуска программы необходимо выполнить команду:

    python main.py

После запуска на экран выводится главное меню приложения.

## 3. Главное меню

Главное меню содержит пять пунктов:

    1. Ввести данные нового сотрудника.
    2. Вывести таблицу со списком сотрудников.
    3. Изменить данные сотрудника.
    4. Удалить информацию о сотруднике.
    5. Выйти из приложения.

Для выбора пункта необходимо ввести соответствующую цифру (1–5)
и нажать клавишу Enter. Приложение работает циклически и завершает
работу только после выбора пункта «5».

## 4. Пункт 1. Ввод данных нового сотрудника

При выборе пункта 1 программа последовательно запрашивает следующие поля:

1. **Фамилия и инициалы** - строковое значение, например: `Иванов И.И.`
2. **Занимаемая должность** - строковое значение, например:
   `Инженер-программист`.
3. **Заработная плата (руб.)** - положительное число, например: `95000`.
4. **Год поступления на работу** - целое число в диапазоне от 1900
   до текущего года, например: `2015`.

После ввода данных о сотруднике программа задаёт вопрос:

    Добавить ещё одного сотрудника?
    1. Да
    2. Нет

Ответ `1` - продолжить ввод, ответ `2` - вернуться в главное меню.

## 5. Пункт 2. Вывод таблицы со списком сотрудников

При выборе пункта 2 программа выводит таблицу со всеми сотрудниками,
включая номер записи, фамилию, должность, зарплату, год поступления
и рассчитанный стаж.

Если список сотрудников не пуст, дополнительно задаётся вопрос:

    Выполнить фильтрацию по стажу?
    1. Да
    2. Нет

При выборе `1` программа запрашивает пороговое значение стажа (в годах)
и выводит список сотрудников, стаж которых строго превышает заданное
значение. Если таких сотрудников нет, выводится сообщение:

    Таких сотрудников нет.

## 6. Пункт 3. Изменение данных сотрудника

При выборе пункта 3 программа выводит таблицу со списком сотрудников
и запрашивает номер записи для изменения. Номер вводится в диапазоне
от 1 до количества сотрудников. Для отмены операции можно ввести `0`.

После выбора сотрудника программа предлагает выбрать изменяемое поле:

    1. Фамилия и инициалы.
    2. Занимаемая должность.
    3. Заработная плата.
    4. Год поступления на работу.
    0. Отмена.

После выбора поля запрашивается новое значение. При некорректном вводе
программа выводит сообщение об ошибке и повторяет запрос.

## 7. Пункт 4. Удаление информации о сотруднике

При выборе пункта 4 программа выводит таблицу со списком сотрудников
и запрашивает номер записи для удаления (аналогично пункту 3).

После выбора сотрудника запрашивается подтверждение:

    Вы действительно хотите удалить эту запись?
    1. Да
    2. Нет

При выборе `1` запись удаляется из списка, при выборе `2` операция
отменяется.

## 8. Пункт 5. Выход из приложения

При выборе пункта 5 программа выводит прощальное сообщение
и завершает работу:

    Завершение работы приложения. Всего доброго!

|---------------------------------------------|----------------------------------|-----------------------------------------|
| «Некорректный ввод. Введите число от 1 до 5»| Введён номер пункта вне диапазона| Повторить ввод, указав число от 1 до 5. |
| «Ошибка ввода. Введите число.»              | Введено нечисловое значение      | Повторить ввод, указав число.           |
| «Зарплата не может быть отрицательной.»     | Введено отрицательное значение   | Повторить ввод, указав неотрицательное  |
|                                             |                                  | число.                                  |
| «Год вне допустимого диапазона.»            | Введён год вне диапазона         | Повторить ввод, указав год в диапазоне  |
|                                             | 1900-текущий год.                | 1900-текущий год.                       |
| «Список сотрудников пуст.»                  | Попытка выполнить операцию       | Сначала добавить хотя бы одного         |

## 10. Завершение работы

Программа завершает работу автоматически после выбора пункта «5»
главного меню. Все введённые данные сохраняются только в течение
сеанса работы - при следующем запуске список сотрудников будет пуст.
